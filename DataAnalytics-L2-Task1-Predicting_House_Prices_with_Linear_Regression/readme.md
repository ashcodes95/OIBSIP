# 🏡 House Price Prediction using Linear Regression

> 📊 A Machine Learning project that predicts house prices using **Linear Regression** with complete **EDA, Data Preprocessing, Feature Engineering, Model Evaluation, and Regularization**.

---

## 📌 Project Overview

This project demonstrates an end-to-end Machine Learning workflow for predicting house prices using **Linear Regression**. It includes data analysis, preprocessing, model training, evaluation, visualization, and comparison with **Ridge** and **Lasso Regression** models.

---

## 🚀 Features

- 📂 Load and explore the dataset
- 🔍 Perform Exploratory Data Analysis (EDA)
- 🧹 Handle missing values
- 🏷️ Encode categorical variables using One-Hot Encoding
- 📊 Correlation analysis and heatmaps
- ✂️ Train-Test Split (80:20)
- 🤖 Train a Linear Regression model
- 📈 Evaluate model performance using:
  - Mean Squared Error (MSE)
  - Root Mean Squared Error (RMSE)
  - R² Score
- 📉 Visualize Actual vs Predicted values
- 📌 Residual Analysis
- 📋 Feature Coefficient Analysis
- ⭐ Compare Linear Regression with Ridge & Lasso Regression
